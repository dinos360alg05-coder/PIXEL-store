# PIXEL STORE // arcade shop starter

Static, mobile-first storefront for PC gear, games, phones and PC builds. It uses plain HTML/CSS/JavaScript with Supabase Postgres and Auth. No build step and no payment processing: customers send their order to WhatsApp, then arrange payment and delivery in the chat.

## Run locally

Run `node dev-server.cjs` and visit `http://localhost:4173`. A server is needed for Supabase Auth and browser module/CDN behavior. With the Supabase placeholders untouched, the 40-item bilingual demo catalog works from `seed-data.js`.

## Supabase setup

1. Create a Supabase project.
2. Open **SQL Editor** and run `schema.sql`, then run `seed.sql`.
3. The schema creates the public `product-images` bucket and storage policies. The bucket is public-read; authenticated uploads, updates and deletes require the admin allow-list.
4. Create the first admin user in **Authentication → Users** (email/password). Copy that user's UUID. In SQL Editor, run `insert into public.admin_users(user_id) values ('YOUR_AUTH_USER_UUID');`. This allow-list table is the authorization source. Only the project owner can add allow-list members; never expose an admin service key in browser code.
5. In `config.js`, set `SUPABASE_URL` and the project's public anon/publishable key. Never put a `service_role` or secret key in `config.js`.
6. Visit `/admin.html`, sign in with that Auth user's email and password, and manage product rows. RLS enforces access even if someone calls the API outside the admin UI.

The frontend product layer requests active products and categories, briefly caches them in `sessionStorage`-compatible local storage, and falls back to `seed-data.js` when Supabase is missing or unavailable. Public policies expose active products and configs. `admin_users` has no client write policy; bootstrap it only from the trusted SQL editor.

## Store settings

Edit `config.js` once to set `STORE_NAME`, `WHATSAPP_NUMBER` (country code, digits only), `CURRENCY`, `LOCALE`, Supabase credentials and the scene key. Prices are formatted through `Intl.NumberFormat`. Set a real WhatsApp number before taking orders. The primary storefront currency is DZD; review sample catalog prices before publishing.

## Fonts and scene

Latin UI uses Silkscreen and Press Start 2P. Arabic uses Reem Kufi with strong contrast and generous line height; the readable-font setting switches the Latin body UI to Arial. I checked Unixel (English/Arabic pixel typeface) and its repository contains an OFL-1.1 license, which permits web embedding. This environment could not retrieve its binary font asset, so the working storefront currently uses the readily available Reem Kufi web font. To ship Unixel locally, download `unixel-Regular.woff2` and `OFL.txt` from [MDarvishi5124/Unixel](https://github.com/MDarvishi5124/Unixel), place them in `/fonts`, then add `@font-face { font-family: Unixel; src: url('/fonts/unixel-Regular.woff2') format('woff2'); font-display: swap; }` and use it for `[dir=rtl]`. The pixel scene is generated by `scene.js` on a capped low-resolution canvas; `SCENE` in `config.js` is the scene switch point.

## Deploy

Deploy this folder as a static site to Netlify, GitHub Pages, Vercel, or Cloudflare Pages. Set Supabase Auth's site URL and redirect allow-list to the deployed origin and local preview origin you use. Restrict production admin allow-list membership. Replace the generated product art with public images in the product-images bucket; put their public URLs in each product's `images` array. Use descriptive product names and accurate stock/price data before launch.

## Included flows

- Hash routes: home, category, product detail, cart, wishlist, PC builds, phone comparison and not-found.
- Search suggestions, category filters, price/stock filters, sort and grid/list mode.
- Persistent cart and wishlist; WhatsApp order text includes variants, quantities, line totals, grand total, and optional name/city/notes. Copy-to-clipboard is available as a fallback.
- Settings for sound, scanlines, motion and readable font. Web Audio is silent until enabled; canvas pauses while the tab is hidden.
- `admin.html`: Supabase Auth login, product create/edit/delete, stock/active/featured controls, image URL list, JSON/CSV import/export, and category creation.

The admin supports product image URLs and ordering by editing the URL list; direct file uploads and the richer friendly variants/spec editor can be added against the provided storage bucket. Supabase must be configured before admin changes can be used. Seed catalog prices are examples, not live quotes.
