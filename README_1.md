Unixel is a freely licensed Arabic/English pixel typeface under SIL Open Font License 1.1: https://github.com/MDarvishi5124/Unixel

The downloadable woff2 could not be fetched in this offline environment. The app currently falls back to Reem Kufi from Google Fonts for Arabic. When adding the font binary, include the upstream OFL.txt and define it in styles.css using @font-face and font-display: swap.
